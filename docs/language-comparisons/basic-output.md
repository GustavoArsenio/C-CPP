# Basic Output in C and C++

The canonical C example is
[`01-hello.c`](../../tracks/c/01-foundations/basic/01-hello.c); its C++
counterpart is
[`01-hello.cpp`](../../tracks/cpp/01-foundations/basic/01-hello.cpp).

Both use their language's standard library and print the same conceptual
message. The C example uses `puts`, which appends a newline. The C++ example
uses the output stream and an explicit newline character. This small pair
illustrates different standard I/O interfaces without claiming a performance
difference. No timing comparison has been measured.
