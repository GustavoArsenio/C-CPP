# Licensing Status

The committed baseline contains no root `LICENSE` file. No license has been
applied during this refactor because doing so would grant permissions to
redistribute code and educational materials whose ownership and provenance
have not yet been reviewed.

**Proposal for maintainer decision:** use the MIT License for original source
code and documentation if the project maintainer confirms the materials are
owned or licensed for redistribution. It is short and permissive, which fits
an educational repository that encourages reuse. PDFs, archived assignments,
and third-party content must be reviewed separately; a root license must not
silently relicense those materials.

Before adding a license, confirm authorship/permission for historical sources,
assignment PDFs, fixtures, and any contributions, then add copyright notices
or attribution as appropriate. Until this is resolved, the repository does
not communicate an open-source license for its contents.
