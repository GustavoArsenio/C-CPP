# Code of Conduct

We want this project to be a respectful place to learn and contribute.

Be considerate, patient, and constructive. Focus critique on code and ideas.
Do not harass, insult, discriminate against, or intimidate participants.
Respect privacy and do not publish another person's personal information
without permission.

Project maintainers may remove content or restrict participation when conduct
harms the learning environment. To report a concern, contact the repository
maintainers privately through the GitHub repository's contact options.
